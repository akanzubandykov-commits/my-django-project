# Ustaz Portfolio — мұғалімдердің өзі толтыратын портфолио және рейтинг сайты (Django)

## Жылдам жаңарту / іске қосу (Windows)
Жоба папкасындағы `start.bat` файлын екі рет басыңыз: ол кітапханаларды орнатады, миграцияларды жасап қолданады, санаттарды жүктейді және серверді іске қосады.
Алғаш рет іске қосқанда бір рет қана `python manage.py createsuperuser` және `python manage.py import_schools schools_example.csv` орындаңыз.

## Іске қосу
```bash
python -m venv venv
venv\Scripts\activate          # Windows  (Linux/Mac: source venv/bin/activate)
pip install -r requirements.txt
python manage.py makemigrations portfolio
python manage.py migrate
python manage.py seed           # 11 санат + үлгі критерийлер
python manage.py import_schools schools_example.csv   # мектептер тізімі (өз файлыңызбен ауыстырыңыз)
python manage.py createsuperuser
python manage.py runserver
```
Сайт: http://127.0.0.1:8000/  ·  Әкімші панелі: http://127.0.0.1:8000/admin/

## Санаттардың түсініктемесі (басты бетте)
Басты беттегі әр санат карточкасын (Білім сапасы, Жетістіктер, ...) басқанда терезе ашылады: онда түсініктеме, ұпай беру тәртібі (Баллдар жүйесінен алынады) және «Тіркеліп бастау» батырмасы бар.
Түсініктемені сайт әкімшісі панельде «Санаттардың түсініктемесі» бөлімінде жазады.

## Мектеп әкімшілері (директор және директордың орынбасары)
Рөл құжатпен расталғаннан кейін (әкімші панелінде «Рөл сұраныстары») олар мектеп әкімшісі болады және кабинетте мыналарды көреді:
- «Менің мектебім»: өз мектебінің мұғалімдер тізімі, «Мұғалімді қосу» батырмасы, әр мұғалімнің қасында «Өшіру»;
- «Жазбаларды тексеру»: өз мектебінің мұғалімдері жүктеген құжаттарды растау/қабылдамау (өз жазбасын өзі растай алмайды);
- «Мектеп есебі»: ұпайлар кестесі және Excel (CSV).
Директор өз мектебінің кез келген мұғаліміне «Әкімші» рөлін бере алады және ала алады («Менің мектебім» → «Әкімші ету» / «Әкімшілікті алу»); директор рөлін тек сайт әкімшісі құжатпен береді.
Өшіру ережесі: өзін де, сайт әкімшісін де өшіре алмайды; директор мектеп әкімшісін өшіре алады, әкімші тек жай мұғалімді. Мұғалімді өшіргенде оның жазбалары мен құжаттары да өшеді.
Сайт әкімшісі (superuser) панельде кез келген мектепке мұғалім қосып, кез келген мұғалімді өшіре алады.

## Сайттың жалпыға ашық басты беті
Оны КІМ КӨРЕДІ: кез келген адам. Кесте кім қарағанына байланысты өзгереді:
- кірмеген қонақ: мектептер рейтингі (мұғалімдердің аты жоқ) немесе расталған деректер жоқ болса, үлгі кесте;
- кірген мұғалім/әкімші/директор: тек ӨЗ мектебінің мұғалімдер тізімі (басқа мектептің мұғалімдері көрінбейді);
- кабинеттің және панельдің жоғарғы жағындағы «Сайт беті» сілтемесі арқылы осы бетке өтеді.

## Мұғалім кабинеті: «Басты бет»
Кіргеннен кейін мұғалім «Басты бет» бөліміне түседі: өз ұпайы, өз мектебіндегі орны, ӨЗ мектебінің мұғалімдер рейтингі және «Мектептер рейтингі»
(мектеп ұпайы = расталған ұпайлар қосындысы ÷ мұғалімдер саны; (i) белгісінде түсініктеме бар). Басқа мектептің мұғалімдері көрінбейді, тек мектеп атаулары мен орташа ұпайы.
Жалпыға ашық басты беттегі кесте де енді мұғалімдердің емес, мектептердің рейтингін көрсетеді.

## Әкімші панелі (суперпайдаланушы)
`createsuperuser` жасаған адам кіргенде басты бетке емес, `/panel/` әкімші панеліне түседі. Онда:
- **Шолу:** мұғалімдер, мектептер, күтіп тұрған/расталған жазбалар саны, соңғы тіркелгендер.
- **Мұғалімдер:** кім тіркелді, іздеу, мектеп бойынша сүзу, ұпайы; «Әкімші» және «Директор» рөлдерін беру.
- **Жазбаларды бағалау:** барлық мектептің жазбалары, құжатты ашу, растау немесе қабылдамау (түсініктемемен).
- **Баллдар жүйесі:** әр санаттың критерийлері мен ұпайларын өзгерту, жаңа критерий қосу, өшіру, қайта есептеу.
- **Мектептер:** тізімді қарау және жаңа мектеп қосу.
Кіргеннен кейін жоғарғы жақта «Шығу» батырмасы тұрады (басты бетте де).

## Әкімші және директор рөлдері (құжатпен растау)
Әкімші пен директор та мұғалім: екі рөл қатар жүреді. Тіркелгенде «Мен мектеп әкімшісімін» / «Мен директормын» белгісін қойып, тағайындау бұйрығын жүктейді
(кейін де кабинетте «Әкімші / директор рөлі» бөлімінен сұрауға болады). Рөл АВТОМАТТЫ берілмейді: әкімші панелінде «Рөл сұраныстары» бөлімінде
құжатты тексеріп, «Растау» немесе «Қабылдамау» басады, адамға email жіберіледі. Расталғанға дейін ол жай мұғалім ретінде жұмыс істейді.
Әкімші рөлді «Мұғалімдер» кестесіндегі белгі арқылы тікелей беріп-алуға да болады.

## Құпиясөз / логин ұмытылса
- Мұғалім: кіру бетіндегі «Логин немесе құпиясөзді ұмыттым» → email жазады → поштаға ЛОГИНІ және жаңа құпиясөз жасау сілтемесі (24 сағат жарамды) келеді.
- Құпиясөзді кабинет ішінде «Құпиясөзді өзгерту» арқылы да өзгертуге болады (әкімші де).
- Әкімші панелінде: мұғалімнің логині көрінеді, «Жаңа құпиясөз» батырмасы уақытша құпиясөз береді. Ескі құпиясөзді көру мүмкін емес: ол хэштелген.
- Суперпайдаланушы өз логинін/құпиясөзін ұмытса: `python manage.py changepassword ЛОГИН` (логинді білмесе: `python manage.py shell -c "from django.contrib.auth import get_user_model as g;print(list(g().objects.filter(is_superuser=True).values_list('username',flat=True)))"`).
- Тіркелгенде де логин көрсетілген хат жіберіледі (құпиясөз хатқа жазылмайды).

### Пошта баптауы
Әдепкіде хаттар `runserver` терезесіне шығады (сынау үшін). Нақты поштаға жіберу үшін серверді іске қоспас бұрын (Windows cmd):
```
set EMAIL_HOST=smtp.gmail.com
set EMAIL_PORT=587
set EMAIL_HOST_USER=сіздің_адрес@gmail.com
set EMAIL_HOST_PASSWORD=қолданба_құпиясөзі
set DEFAULT_FROM_EMAIL=сіздің_адрес@gmail.com
python manage.py runserver
```
Gmail үшін екі сатылы растауды қосып, «Қолданба құпиясөзін» (App password) жасаңыз; аккаунттың негізгі құпиясөзін жазбаңыз. Басқа пошта (mail.ru, yandex, корпоративтік) үшін өз SMTP мекенжайын қойыңыз.

## Мектептер тізімі
Тіркелуде мұғалім мектепті аудан бойынша топталған тізімнен таңдайды (қолмен жазбайды), сондықтан қайталанатын атаулар болмайды.
Тізімді екі жолмен толтырасыз:
- `python manage.py import_schools файл.csv`: әр жол `Мектеп атауы;Аудан` (UTF-8). `schools_example.csv` үлгісін қараңыз (ондағы мектептер ойдан шығарылған үлгі, өзіңіздің нақты тізіміңізге ауыстырыңыз).
- `/admin/` → Мектептер: бір-бірлеп қосу, өзгерту.

## Қалай жұмыс істейді
1. Мұғалім `/register/` арқылы өзі тіркеледі, жеке кабинетке түседі (`/kabinet/`).
2. «Деректерді енгізу»: санат таңдайды, құжатпен жазба жібереді (мәртебесі «Күтуде»).
3. Әкімші пен директор да мұғалім: олар да өз жазбаларын жібереді, рейтингке қатысады. Қосымша рөл `/admin/` → Мұғалімдер
   бөлімінде «Әкімші» және/немесе «Директор» белгісін қою арқылы беріледі (екеуін бірге де қоюға болады).
   Сонда кабинетте «Жазбаларды тексеру» мен «Мектеп есебі» бөлімдері ашылады (тек өз мектебінің деректері).
   Өз жазбасын өзі растай алмайды: мектеп әкімшісінің жазбасын директор (немесе басқа әкімші) растайды.
4. Расталған жазбаның ұпайы (Критерий кестесіндегі мән) мұғалімнің рейтингіне қосылады.
5. Рейтинг «Менің рейтингім» бетінде: жалпы ұпай, мектептегі орын, санаттар бойынша.

## Ұпай ережесі
`seed` командасындағы ұпайлар (1, 2, 3, 5, 8) тек ҮЛГІ. Нақты ережені `/admin/` → Критерийлер бөлімінде өзгертіңіз.

## Қауіпсіздік (жариялау алдында)
- `SECRET_KEY`, `DEBUG=0`, `ALLOWED_HOSTS` ортаның айнымалылары арқылы беріледі.
- Құжаттар `private_media/` ішінде, тек иесі мен өз мектебінің әкімшісі ашады (`/kabinet/doc/<id>/`).
- Жариялағанда HTTPS және PostgreSQL қолданыңыз (settings.py ішіндегі DATABASES).
- Мұғалімдердің жеке деректері сақталады: ҚР «Дербес деректер туралы» заңын сақтаңыз.

## Құрылым
- `portfolio/models.py` — Мектеп, Мұғалім, Санат, Критерий, Жазба
- `portfolio/views.py` — тіркелу, кабинет, жазба жіберу, тексеру, рейтинг
- `templates/`, `static/` — бекітілген дизайн (шаңырақ, қошқар мүйіз, жасыл-қызыл-алтын)

## Сабақ конструкторы (ЖИ көмекші)
Мұғалімнің кабинетінде «Сабақ конструкторы» бөлімі: пәні профильден алынады, мұғалім сыныпты, сабақ тілін (қазақша, русский, English), тақырыпты және дизайнды таңдайды,
қаласа ЖИ-ге ұсыныс жазады. ЖИ толық сабақ құрылымын жасайды (ұйымдастыру, қызығушылықты ояту, теория, практика, деңгейлік тапсырмалар, рефлексия, үй тапсырмасы, жауаптар).
Мұғалім әр кезеңді қолмен өңдейді, ретін ауыстырады, кезең қосады/өшіреді немесе ЖИ-ден өзгеріс сұрайды. «Сабақ режимі»: сыныпта үлкен мәтінмен, кезең-кезеңімен көрсету және таймер; «Басып шығару».
ЖИ қосу: `secrets.bat.example` файлын `secrets.bat` деп көшіріп, ішіне Anthropic API кілтін жазыңыз (кілтті ешкімге бермеңіз, git-ке салмаңыз).
Кілт жоқ болса да бөлім жұмыс істейді: бос қаңқа жасалады. Айлық шек: `LESSON_AI_MONTHLY_LIMIT` (әдепкі 30 сұраныс/мұғалім); сайт әкімшісіне шек жоқ.
